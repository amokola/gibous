# 🌙 Gibous | Telegram Duel Arena

> **Fast duels. Real ranks. Play-credit rewards.**

Gibous is the quick-duel arena where Telegram players challenge friends, climb ranks, and win play-credit pots through fair server-run games.

## 🕹️ 3-in-1 Duel Games

1. **🔴🟢 Four in a Row (Connect 4)**:
   - Drop discs. Connect four. Win the pot.
2. **🐍 Snake & Ladder (Classic 1–100)**:
   - Classic race to tile 100 on a 10×10 Boustrophedon board with snakes and wooden ladders.
3. **✂️ Rock Paper Scissors**:
   - Fast best-of-three mind game with simultaneous clash reveals.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
# Start frontend & backend concurrently:
npm run start

# Or start frontend only:
npm run dev

# Or start WebSocket server only:
npm run server
```

Open `http://localhost:5173` in your browser.
